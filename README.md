# 抖音直播运营助手(Live Operation Assistant)

**抖音直播运营助手** 是一款基于 Python 与 Chrome 浏览器自动化技术的抖音直播间智能辅助工具。它集成了 **DeepSeek** 和 **豆包 (Doubao)** 等先进的大语言模型，旨在帮助主播自动化处理繁琐的互动任务，活跃直播间气氛。

---

## ✨ 核心功能

*   **🤖 智能大脑**: 对接 DeepSeek/豆包大模型，智能回复弹幕、@消息，拒绝机械式回答。
*   **👋 自动场控**: 识别观众进场自动欢迎，检测到礼物/关注/点赞自动致谢。
*   **🔥 氛围活跃**: 支持 AI 随机闲聊、冷场自动暖场、定时发送预设话术。
*   **🎙️ 语音互动**: (实验性) 识别主播语音，根据主播说的话自动配合发送弹幕。
*   **🛡️ 安全稳定**: 采用非侵入式 Chrome 浏览器增强技术，模拟真人操作，降低风控风险。

---

## 🚀 快速开始

### 1. 环境安装
确保已安装 Python 3.10+ 和 Google Chrome 浏览器。
为了避免依赖冲突，建议创建 Python 虚拟环境：
```powershell
# 1. 创建虚拟环境
python -m venv .venv
.venv\Scripts\activate

# 2. 安装依赖
pip install -r requirements.txt
```

### 2. 配置软件
打开 `config/config.json`，填入您的配置信息：
*   `douyin.room_url`: 目标直播间链接。
*   `ai.deepseek.api_key`: (如果您使用 DeepSeek) 填入 API Key。
*   `ai.doubao.api_key`: (如果您使用 豆包) 填入 API Key。

### 3. 运行助手
```powershell
python src/main.py
```
启动后，软件会自动打开 Chrome。请在弹出的浏览器中**登录抖音账号**，然后助手即可开始工作。
