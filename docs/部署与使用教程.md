# 直播运营助手 - 部署与打包使用教程

本教程将指导您完成开发环境的搭建、配置文件的修改以及最终 EXE 可执行文件的打包。

---

## 1. 环境准备 (Environment Setup)

在开始之前，请确保您的电脑满足以下要求：

*   **操作系统**: Windows 10 或 Windows 11
*   **浏览器**: Google Chrome (最新版)
*   **编程语言**: Python 3.10 或更高版本


---

## 2. 安装与配置 (Installation)

### 2.1 获取源码
如果您收到了源码压缩包，请将其解压到一个没有中文路径的文件夹中（例如 `D:\Projects\LiveAssistant`）。

### 2.2 创建虚拟环境 (推荐)
为了避免依赖冲突，建议创建 Python 虚拟环境：

```powershell
# 打开 CMD 或 PowerShell 进入项目目录
cd D:\Projects\LiveAssistant

# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
.venv\Scripts\activate
```

### 2.3 安装依赖库
在激活的虚拟环境中，安装项目所需的第三方库：

```powershell
pip install -r requirements.txt
```

> **注意**: 如果安装速度较慢，可以使用清华源加速：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

---

## 3. 配置文件说明 (Configuration)

项目核心配置位于 `config/` 目录下。 **打包后，该目录必须与 EXE 文件位于同一级文件夹中。**

### 3.1 `config.json` (系统配置)
用于配置 AI 密钥、直播间链接和功能开关。

*   **douyin**:
    *   `anchor_name`: 主播助理昵称（用于 AI 识别“我”）。
    *   `room_url`: 默认直播间链接。
	*   `at_keywords`: @互动关键词
*   **ai**:
    *   `provider`: 设置为 `deepseek` 或 `doubao`。
    *   `deepseek`: 填入 DeepSeek API Key 和 Model。
    *   `doubao`: 填入 豆包 API Key 和 Model (Endpoint ID)。
        *   `reply_probability`: 0.3,   //AI 随机互动 (活跃气氛)概率 
        *   `warmup_interval`: 180,     //自动暖场 (定时随机发送) 180秒。本地interactive里内容
        *   `ai_warmup_interval`: 120   //AI 冷场自动暖场 (监控空闲)  120秒，event_idle里描述词
	
	
	
*   **features**: 各类功能的默认开启状态（也可以在软件界面修改）。

### 3.2 `speech_templates.json` (话术/提示词)
*   **welcome**: 欢迎语列表，随机抽取。
*   **thanks_gift**: 感谢礼物话术。
*   **ai_prompts**: 定义 AI 的人设（System Prompt）和回复逻辑。

## 4. 运行与测试 (Running)

在开发通过以下命令启动软件：

```powershell
# 确保虚拟环境已激活
python src/main.py
```

启动后：
1.  输入 **AI API Key**（如果配置文件未填）。
2.  点击 **“打开浏览器 / 去登录”**，账号登录抖音。
3.  输入 **直播间链接**，点击 **“进入直播间”**。
4.  观察控制台日志，确认弹幕监听正常。

## 5. 打包发布 (Packaging)

本项目已提供一键打包脚本 `build.bat`，它会自动处理依赖项和资源文件。

### 5.1 使用打包脚本 (推荐)
直接双击项目根目录下的 `build.bat`，或者在终端运行：

```powershell
.\build.bat
```

**脚本会自动执行以下操作**：
1.  清理旧的 `build` 和 `dist` 文件夹。
2.  调用 `PyInstaller` 进行打包，自动处理隐藏导入 (`playwright`, `speech_recognition` 等)。
3.  将图片资源 (`favicon.ico`, `styles.qss`, `zsm.jpg`) 打包进 EXE 内部。
4.  **重要**: 自动把 `config/` 文件夹复制到输出目录。

### 5.2 打包结果
打包完成后，生成的文件位于 `dist/` 目录下：

```text
dist/
├── config/                 # 配置文件 (必须存在)
│   ├── config.json
│   └── speech_templates.json
└── LiveAssistant.exe       # 可执行程序
```

您可以将整个 `dist` 文件夹压缩发送给用户。

> **警告**: `LiveAssistant.exe` 不能单独移动！它必须和 `config` 文件夹在一起才能正常读取配置。

### 5.3 手动打包 (高级)
如果 `build.bat` 无法使用，可手动执行以下命令：

```powershell
pyinstaller --noconfirm --onefile --windowed ^
    --name "LiveAssistant" ^
    --icon "src/gui/favicon.ico" ^
    --add-data "src/gui/styles.qss;src/gui" ^
    --add-data "src/gui/favicon.ico;src/gui" ^
    --add-data "src/gui/zsm.jpg;src/gui" ^
    --hidden-import "playwright" ^
    --hidden-import "speech_recognition" ^
    --hidden-import "pyaudio" ^
    --hidden-import "pkg_resources" ^
    --hidden-import "setuptools" ^
    src/main.py
```

## 6. 常见问题 (FAQ)

**Q1: 打包后的软件打不开，提示 "Failed to execute script main"？**
*   **原因**: 缺少配置文件或资源丢失。
*   **解决**: 确保 `config` 文件夹和 EXE 在一起。在 CMD 中运行 EXE 查看具体报错信息。

**Q2: 浏览器无法启动或报错？**
*   **解决**: 确保电脑安装了 Google Chrome。软件会自动寻找 Chrome 路径，如果安装在非标准路径，可能需要手动指定（需修改源码）。

**Q3: 语音识别不生效？**
*   **解决**: 确保安装了麦克风驱动，并且 `pyaudio` 库安装正确（Windows 下有时需要下载 .whl 文件手动安装）。

**Q4: AI 回复报错？**
*   **解决**: 检查 API Key 是否过期，或网络是否通畅（DeepSeek 有时需要国内代理或直连）。
