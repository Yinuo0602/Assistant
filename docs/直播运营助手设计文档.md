## 1. 产品简介 (Introduction)

**直播运营助手** 是一款专为抖音直播间设计的桌面端智能辅助软件。它基于 Python 与 Chrome 浏览器自动化技术，集成了 DeepSeek 和 豆包 (Doubao) 等先进的大语言模型 (LLM)。

本软件旨在通过自动化手段降低主播的运营成本，提升直播间互动率。核心能力包括：自动欢迎观众、智能感谢礼物/关注/点赞、AI 拟人化闲聊互动、以及主播语音识别辅助。

### 核心亮点
- **非侵入式架构**: 基于 Chrome 浏览器增强，模拟真实用户行为，安全稳定。
- **双模 AI 驱动**: 支持 DeepSeek (高智商) 和 豆包 (高性价比) 双模型切换。
- **高度可配置**: 所有话术、规则、AI 提示词均支持实时热更新，无需重启。
- **拟人化交互**: 具备随机延迟、多变话术和上下文理解能力，拒绝生硬机器风。

## 2. 功能详解 (Features)

### 2.1 基础互动功能
| 功能模块 | 描述 | 触发机制 |
| :--- | :--- | :--- |
| **自动欢迎** | 识别新进入直播间的观众并致欢迎词。 | 监听 `WebcastMemberMessage` 事件。支持去重 (10秒内不重复欢迎同一人)。 |
| **感谢礼物** | 识别观众送礼行为，念出礼物名称并感谢。 | 监听 `WebcastGiftMessage` 事件。识别礼物数量和连击。 |
| **感谢关注** | 识别用户关注行为并致谢。 | 监听 `WebcastSocialMessage` (关注类型)。 |
| **感谢点赞** | 识别用户点赞行为并感谢。 | 监听 `WebcastLikeMessage`。支持去重 (30秒内不重复感谢)。 |

### 2.2 AI 智能互动 (Brain)
软件内置 AI 网关，支持对以下场景进行智能化处理：

- **@我 回复**: 当弹幕中包含“助理”或配置的关键词（如 `@小助手`）时，自动调用 AI 进行回复。
- **随机闲聊**: 在开启“AI 随机互动”后，按设定的概率 (如 30%) 随机回复普通弹幕，活跃气氛。
- **AI 暖场**: 当检测到直播间长时间 (如 120秒) 无人发言时，自动请求 AI 生成一段暖场话术打破尴尬。
- **事件拟人化**: 可选将简单的“欢迎/感谢”话术交给 AI 生成，使回复更加生动幽默（需开启“关联控制”）。

### 2.3 辅助功能
- **主播语音识别**: (实验性) 监听麦克风，将主播说的话转为文字日志，未来可用于触发特定场控特效。
- **自动暖场 (规则版)**: 定时 (如每 3 分钟) 发送一条预设的弹幕（如“点点关注不迷路”），独立于 AI。

## 3. 使用操作指南 (User Manual)

### 3.1 环境准备
1. **操作系统**: Windows 10/11。
2. **浏览器**: 必须安装 **Google Chrome** 浏览器。
3. **运行**: 双击 `直播运营助手.exe` 或运行源码 `python src/main.py`。

### 3.2 界面说明
软件主界面分为三大区域：
1. **左侧控制栏**:
    - **账号区**: 输入助手昵称，点击登录按钮启动 Chrome。
    - **连接区**: 输入直播间链接，控制互动的开始与停止。
    - **AI 设置**: 选择模型厂商，填入 API Key。
    - **功能开关**: 勾选需要启用的功能模块。
2. **右侧日志区**:
    - **上方**: 实时弹幕监控窗口。
    - **下方**: 系统运行日志窗口。
3. **顶部标签页**:
    - **互动控制台**: 主操作界面。
    - **高级配置**: 查看和修改 JSON 配置文件。
    - **关于**: 软件信息。

### 3.3 快速启动步骤
1. **登录**: 点击左上角“打开浏览器 / 去登录”，在弹出的 Chrome 窗口中扫码登录抖音账号（建议使用小号作为房管/助理）。
2. **配置**: 确认“功能开关”中已勾选需要的互动功能。
3. **连接**: 在“直播间地址”输入框填入目标直播间 URL（支持短链或长链）。
4. **开始**: 点击“进入直播间 & 开始互动”。浏览器将自动跳转并开始监听弹幕。

### 3.4 高级配置 (Config)
在“高级配置”标签页可以实时修改两个核心文件：
- **`config.json`**: 保存 API Key、直播间链接、功能开关状态等。
- **`speech_templates.json`**: 保存所有固定话术（欢迎语、感谢语）和 AI 的系统提示词 (System Prompts)。

> **提示**: 修改后点击“保存并立即生效”按钮，无需重启软件即可应用新规则。

## 4. 技术开发文档 (Developer Guide)

### 4.1 系统架构
本项目采用模块化分层设计：

- **GUI 层 (`src/gui/`)**: 基于 **PySide6** (Qt) 构建。负责界面展示、信号槽绑定、日志重定向。
    - `mainwindow.py`: 主窗口逻辑。
- **核心层 (`src/core/`)**:
    - `controller.py`: **中央控制器**。管理所有后台线程、事件分发、功能开关逻辑。
    - `browser.py`: **浏览器服务**。封装 Selenium/Playwright 逻辑，负责驱动 Chrome、注入 JS 监听 WebSocket。
    - `event_bus.py`: **事件总线**。实现发布/订阅模式，解耦监听层与业务层。
    - `ai.py`: **AI 网关**。统一封装 DeepSeek 与 Doubao 的 API 调用接口。
    - `executor.py`: **执行器**。负责将最终的回复文本发送到直播间（控制浏览器输入框）。

### 4.2 目录结构
```text
zhibozhushou/
├── config/                 # 配置文件存取
│   ├── config.json         # 用户配置
│   └── speech_templates.json # 话术模板
├── docs/                   # 文档目录
├── src/                    # 源代码
│   ├── core/               # 核心业务逻辑
│   ├── gui/                # 界面代码
│   ├── utils/              # 工具库 (logger, paths)
│   └── main.py             # 程序入口
├── requirements.txt        # Python 依赖
└── build.bat               # 打包脚本
```

### 4.3 关键逻辑流程
1. **监听 (Listen)**:
   - `BrowserService` 启动 Chrome，注入 JS 脚本拦截 WebSocket 流量。
   - 解析 Protobuf/JSON 数据包，提取弹幕、礼物等信息。
   - 通过 `EventBus.publish(EventType.DANMU, data)` 广播事件。

2. **决策 (Decide)**:
   - `LiveController` 订阅事件。
   - 检查功能开关 (`self.features`) 和 去重缓存 (`processed_cache`)。
   - 判断处理方式：
     - **规则匹配**: 命中关键词或特定事件 -> 从 `speech_templates` 随机取话术。
     - **AI 生成**: 命中 @我 或 触发 AI 规则 -> 组装 Prompt 调用 `AIGateway`。

3. **执行 (Act)**:
   - 生成的回复文本放入 `msg_queue` (线程安全队列)。
   - 消费者线程从队列取消息，经过随机延迟 (Random Delay)。
   - 调用 `executor.send_danmu(msg)` 操作浏览器 DOM 写入并发送。

### 4.4 二次开发指南
- **添加新模型**: 在 `src/core/ai.py` 中扩展 `AIGateway` 类，适配新的 API SDK。
- **修改界面**: 修改 `src/gui/mainwindow.py`，使用 `QVBoxLayout` 等布局添加新控件。
- **自定义事件**: 在 `src/core/event_bus.py` 定义新 `EventType`，并在 `browser.py` 中实现抓取逻辑。
